Files selected in the tools

The PDF tools included in this website are designed to process selected files locally in your browser. The supplied tool code does not upload the files you select to our own server. Processing may fail for some file types, protected documents, or very large files. If you modify the code or add a server-side service, update this policy to describe that change accurately.

Our hosting provider may receive standard technical information when you visit the site, such as IP address, browser type, requested page, referring page, and request time, as part of operating and securing the website. Check your host's privacy documentation and update this section to reflect its actual logging and retention practices.

Cookies and advertising

Third parties may place and read cookies in your browser or use web beacons or IP addresses to collect information as a result of ad serving on this website. Learn more at How Google uses information from sites or apps that use its services.

Do not add advertising code until you have reviewed the relevant provider terms and configured any required consent or privacy messaging for your visitors' locations. If you use analytics, embedded content, forms, or additional advertising providers, list them here and explain their actual data practices.

Third-party libraries

Some tools load open-source JavaScript libraries from third-party content delivery networks. A browser may make network requests to those providers to retrieve the library files. Review the current providers and consider self-hosting dependencies if that better fits your security and privacy needs.

Children's privacy

This website is a general-purpose utility and is not intended to collect personal information from children. Do not knowingly collect personal information from children without complying with applicable requirements.
